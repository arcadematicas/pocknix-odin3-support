## Class-H: hipotesis principal (zumbido + entrecortado)
Fransis describe el class-H como **zumbido digital constante + audio casi entrecortado**, no silencio. Eso
encaja con la compander trabajando sin impedancia declarada:

- El include estandar del codec (`codecs/wcd939x/HeadphoneEnableSeq.conf`) hace
  `HPHL/HPHR_COMP Switch 1` (compander **on**), `CLSH Switch 1` y `RX HPH Mode CLS_H_LOHIFI`.
- Nuestro `HiFi.conf` **apaga** la compander despues del include, porque en octubre daba
  "bombeo y entrecortados con la impedancia sin declarar (HPHL/HPHR Impedance = 0)".
- Efectivamente: hoy `amixer -c 0 cget numid=19/20` devuelve **Impedance = 0** (sin declarar).
- Resultado: con COMP on -> entrecortado; con COMP off -> casi mudo con zumbido. Ninguno de los dos
  es el class-H sano.

### Prueba de esta noche (sin recompilar: el kernel 7.2.15-6 ya lleva 2603/2604)
Con auriculares puestos y algo sonando, en la Odin:

    amixer -c 0 cset numid=19 32     # HPHL Impedance (ohmios)
    amixer -c 0 cset numid=20 32     # HPHR Impedance
    amixer -c 0 cset numid=23 on     # HPHL_COMP
    amixer -c 0 cset numid=24 on     # HPHR_COMP
    amixer -c 0 cset numid=14 CLS_H_LOHIFI
    amixer -c 0 cset numid=31 20     # HPHL Volume 0 dB
    amixer -c 0 cset numid=32 20     # HPHR Volume 0 dB

- Si suena limpio y con potencia: **el class-H funciona** y lo que faltaba era declarar la impedancia
  (y dejar la compander encendida). Entonces se fija en el UCM del paquete.
- Si sigue el zumbido: probar impedancias 16 / 24 / 64 y, con el kernel 7, mirar `dmesg | grep clsh`
  (hstart/hstop/HCtl).
- Volver al estado bueno (class-AB) con los mismos comandos: numid 23/24 off, numid 14 CLS_AB.

Documento de referencia del sintoma de octubre: `docs/AUDIO-AURICULARES-20261022.md`.

## Trampa al empaquetar AppImages: makepkg los recorta con strip
`calvos-rustdesk 1.5.3-1` se instalo con el AppImage de **936 KB** (solo el runtime): makepkg aplica
`strip` al ser un ELF, y stripar el runtime **descarta el squashfs anexado**. Sintoma en el dispositivo:

    This doesn't look like a squashfs image. Cannot mount AppImage...

Arreglo: `options=('!strip')` en el PKGBUILD (pkgrel 2). **Todo paquete que envuelva un AppImage lo necesita.**
Comprobacion rapida tras el build: el artefacto debe pesar ~lo mismo que el AppImage original
(rustdesk: 85.5 MB), no ~900 KB.
