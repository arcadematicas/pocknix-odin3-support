## 6. LiquidFrames / Syluxium Motion (nuevo, 27/11/2026)

**Qué es**: frame generation para Linux (competidor de LSFG/MAKO), app **cerrada**, solo
**x86_64**, con su propio motor. "Click to hook" (pulsas Start y clicas la ventana del juego), sin
opciones de lanzamiento, perfiles por juego, modo adaptativo que llena la tasa de refresco
(2,5×, 3,2×…), dual-GPU y escalado FSR1/integer/nearest/bilinear. Requiere glibc 2.36+ y Vulkan 1.2
(RADV/ANV/NVIDIA). **No hay build ARM y Adreno no está en la lista.**

**Veredicto para la Odin**: **no sirve directamente** — un binario x86_64 no puede engancharse al
stack Vulkan aarch64 de Turnip (el mismo muro que tenía MAKO x86).

**Lo interesante**: el motor, **Syluxium Motion**, es **MIT, C++20, Vulkan 1.2+, `dlopen` de
libvulkan**, y se compila con CMake sin dependencias raras → **es compilable para aarch64**. Sería
una alternativa al port comunitario de MAKO (GPL y con host x86 para el FG).

**Primer paso barato (30 min)**: clonar `Syluxium-Industries/Syluxium-motion`, compilar en la Odin
(`cmake -S . -B build -G Ninja`) y ver si el motor construye y su programa de ejemplo funciona con
Turnip. Si compila, evaluar una capa Vulkan aarch64 de por medio (proyecto, no apaño).
