### 🔑 La lección del stage (huevo y gallina) — no volver a pelearse con ella
`scripts/stage-check.sh` calcula el "reach" desde los **roots** (`pocknix-core`,
`pocknix-steam-full`, `pocknix-desktop-full`, `pocknix-emulation-full`,
`pocknix-device-<soc>`) **contra el repo LIVE** (`UNIVERSE = sm8750 stage base`: *el live gana
al stage*). Por eso las aristas nuevas de un paquete **no se ven** hasta que ese paquete está
publicado. Lo que **sí** funciona (y se usó):

```bash
# 0) Sincronizar centro -> arbol en el PC y comprobar
tools/sync-to-os.sh && tools/check-sync.sh

# 1) PRIMERO el paquete que trae las aristas nuevas (aqui el BSP), saltando la puerta UNA vez:
DEVICE=sm8750 POCKNIX_STAGE_CHECK_SOCS=sm8750 POCKNIX_STAGE_NOCHECK=1 make stage PKG="pocknix-bsp-sm8750"
DEVICE=sm8750 POCKNIX_REPO_GPG_KEY="pocknix-repo@arcadematicas" make publish

# 2) Ya con el live actualizado, el resto pasa la puerta NORMALMENTE:
DEVICE=sm8750 POCKNIX_STAGE_CHECK_SOCS=sm8750 make stage-shared PKG="..."
DEVICE=sm8750 make publish-shared
DEVICE=sm8750 POCKNIX_STAGE_CHECK_SOCS=sm8750 make stage PKG="linux-pocknix-sm8750 mangohud"
DEVICE=sm8750 make publish
```
⚠️ **`DEVICE=sm8750` es obligatorio también en `make stage`/`publish`**: sin él, `stage` se va
al mirror de **sm8550** (`error: pocknix-bsp-sm8750: no artifact in .../localrepo/sm8550`).
