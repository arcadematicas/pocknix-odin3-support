## 2. Kernel con `1034` (panel ICNA35xx) — **el importante**

**Qué**: asentar 120 ms tras el reset del panel y reintentar su init hasta 3 veces. Candidato a
arreglar el **cuelgue al cambiar a escritorio** (y el mismo fallo de Jarvis tras suspender):
`panel-chipone: failed to initialize panel: -110` → DPU atascado → `a8xx_recover: cx gdsc didn't collapse`.

**Artefactos** (preparados en `pc-local:/home/fransis/rollback/kernel-1034/`):
- `KERNEL` — 18.108.416 B, md5 **`9ac99728c427ec77`**
- `modules-7.2.12.tar.zst` — 457 entradas

**Instalación** (la hago yo por SSH cuando digas; resumen):
```bash
# en la Odin
sudo cp -a /flash/KERNEL /flash/KERNEL.bak-$(date +%Y%m%d-%H%M)
sudo cp KERNEL /flash/KERNEL
sudo tar --zstd -xf modules-7.2.12.tar.zst -C /lib/modules/7.2.12/
sudo depmod -a 7.2.12
sudo systemctl reboot
```
**Regla de oro**: kernel y módulos del **mismo build** (si no, el kernel rechaza los módulos por BTF:
sin mando y sin sonido).

**Prueba**:
1. `uname -r` → `7.2.12`; `systemctl --failed` vacío.
2. Jugar un momento (que WiFi, mando, audio y panel estén bien).
3. **Cambiar a escritorio** desde el QAM. Repetir **2-3 veces** (ida y vuelta).
   - Si vuelve siempre → **arreglado**: documentar y publicar el kernel.
   - Si se cuelga otra vez → apuntar en qué punto; rollback del kernel y siguiente candidato
     (forzar re-init del host DSI, o `gamescope 3.17`).

**Rollback**:
```bash
sudo cp -a /flash/KERNEL.bak-<fecha> /flash/KERNEL && sudo systemctl reboot
```
(los módulos viejos siguen en `/lib/modules/7.2.12` mezclados: si el rollback es definitivo, reinstalar
`linux-pocknix-sm8750` desde el repo).
