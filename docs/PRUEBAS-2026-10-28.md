# Pruebas 28/10/2026 — sensores, uhid y salud de batería

## Qué se instala

| Paquete | Versión | Qué trae |
|---|---|---|
| `linux-pocknix-sm8750` | **7.2.12-18** | uhid: leer la cola bajo `qlock` (evita NULL deref y el mando colgado) + battmgr: `charge_full_design` |
| `msm-firmware-loader` | **1.8.0-5** | helper fail-open que apaga la isla SSC en el Odin 3 |
| `hexagonrpc` | **0.5.0-3** | 0008: contesta la petición `apps_std` del ADSP (si no, el ADSP no duerme) |
| `libssc` | **0.4.4-2** | 0005: no leer memoria liberada al cerrar un sensor |

## Orden

```sh
sudo pacman -U linux-pocknix-sm8750-7.2.12-18-*.pkg.tar.xz \
               msm-firmware-loader-1.8.0-5-*.pkg.tar.xz \
               hexagonrpc-0.5.0-3-*.pkg.tar.xz \
               libssc-0.4.4-2-*.pkg.tar.xz
sudo systemctl reboot
```

## Comprobaciones tras el arranque

1. **Kernel y guardia**
   - `uname -r` = `7.2.12`; `/flash/KERNEL` cambia de md5 (el hook 90 lo regenera)
   - `pocknix-kernel-guard` → `OK`; `systemctl --failed` vacío
2. **Batería** (lo nuevo)
   - `cat /sys/class/power_supply/battery/charge_full_design` → **debe dar un número** (antes: ENODATA)
   - `upower -i …/battery_battery | grep -E "energy|capacity|time"` → salud coherente (~8.000 mAh)
   - el **tiempo restante** sigue saliendo (no romper lo que ya iba con nuestro 2108)
3. **Sensores / isla SSC**
   - `cat /run/pocknix-island-off.log` → `hecho`/`island off -> …`
   - `grep -A2 island /run/msm-firmware-loader/hexagonrpc/sensors/config/pakala_power_0.json` → `"data": "0"`
   - **giroscopio funciona** (Steam Input / juego con gyro) y no hay errores de SSC en el journal
4. **Suspender justo después de cerrar un sensor** (el caso que colgaba el SoC en Armada)
   - abrir y cerrar una app que use el giro, y **suspender inmediatamente**
   - debe volver sin cuelgue y sin reinicio de sesión
5. **Mando / uhid**
   - Steam en modo juego, abrir el QAM, mandar feature reports (luz del mando si aplica)
   - el input no debe congelarse; `journalctl -k | grep -i "uhid\|NULL pointer"` sin oops

## Rollback

- **Sensores**: `pacman -U` de `msm-firmware-loader 4`, `hexagonrpc 2`, `libssc 1` (o `pacman -Syu` si el repo aún tiene los viejos).
- **Kernel**: `/flash/KERNEL.bak` + reinstalar `linux-pocknix-sm8750-17` (o `pocknix-rollback`).
- El helper de la isla es fail-open: si algo falla, deja el árbol original y sale sin tocar nada.
