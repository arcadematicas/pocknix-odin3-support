# ======================================================================
# Ficheros de BIOS/firmware que espera cada emulador — DeckStation
# ======================================================================
# Lo usa `deckstation-bios.sh --check` para decirte QUE TE FALTA y DONDE va.
# Los ficheros reales NO van en git (copyright): este fichero es solo la lista.
# Ver bios/README.md para la version larga y como conseguirlas legalmente.
#
# Formato:  <sistema>|<fichero>|<nota>|<alternativas separadas por comas>|<md5 validos>
#
#   - El fichero va en bios/<sistema>/ (esa es la carpeta que se reparte).
#   - "alternativas": cualquiera de ellos vale para dar la fila por cubierta
#     (p. ej. cualquier BIOS de PSX sirve). Se comparan sin distinguir
#     mayusculas/minusculas.
#   - "md5 validos": hashes MD5 del fichero (y alternativas si se conocen).
#     Si la columna NO esta vacia, el --check valida el hash real del fichero:
#     un fichero con el nombre correcto pero hash distinto se marca como
#     "MD5 invalido" (BIOS corrupta/falsa). Si esta vacia, solo se mira el nombre.
#   - El DESTINO de cada sistema lo define bios/deploy-bios.txt.
#
# Ojo: no todos son obligatorios. Muchos cores de RetroArch funcionan sin BIOS
# (o con HLE). Si un sistema no arranca, el log del emulador dira el fichero.
# ======================================================================
