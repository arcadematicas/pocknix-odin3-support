# ======================================================================
# Manifiesto de despliegue de BIOS — DeckStation
# ======================================================================
# Mapea cada subcarpeta de bios/ (organizada por sistema) a los destinos
# donde cada emulador espera encontrar sus BIOS/firmware.
#
# Formato:  <origen en bios/>|<destino relativo a la raiz de DeckStation>|<politica>
#
#   politica (opcional, por defecto "keep"):
#     keep  -> solo se copia si el destino NO existe
#     force -> siempre se sobrescribe
#
#   Token {HOME:NombreApp} = el directorio *.home de Apps/<NombreApp>.
#   Si esa app no esta instalada, la entrada se omite sin error.
#
# Una misma carpeta puede aparecer varias veces (varios destinos).
# Los ficheros reales NO van en git (copyright): solo este manifiesto y el
# README. Ver bios/README.md para que ficheros necesita cada sistema.
# ======================================================================
