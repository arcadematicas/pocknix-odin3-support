# ======================================================================
# Manifiesto de despliegue de configs — DeckStation
# ======================================================================
# Mapea cada config de fabrica (configs/) a su destino real dentro de
# DeckStation, para que una instalacion nueva quede reproducible sin
# depender de un payload externo.
#
# Formato:  <origen en configs/>|<destino relativo a la raiz de DeckStation>|<politica>
#
#   politica (opcional, por defecto "keep"):
#     keep  -> solo se copia si el destino NO existe (respeta cambios del usuario)
#     force -> siempre se sobrescribe (ficheros que son 100% nuestros)
#
#   Token {HOME:NombreApp} = el directorio *.AppImage.home de Apps/<NombreApp>.
#   Si esa app no esta instalada, la entrada se omite sin error.
#
# El destino puede ser un fichero o un directorio (se copia su contenido).
# ======================================================================
